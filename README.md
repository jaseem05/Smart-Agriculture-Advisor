# Smart Agriculture Advisor

A machine learning-based web application that provides crop recommendations and predicts market prices based on agricultural and market conditions.

## Features

- Crop recommendation based on:
  - Temperature
  - Rainfall
  - Soil type
  - Cultivation month
- Market price prediction using XGBoost
- Demand and state-based market analysis
- Interactive crop price and demand dashboard
- Cultivation advice and weather alerts
- Flask-based web interface

## Technologies Used

- Python
- Flask
- Machine Learning
- Scikit-learn
- XGBoost
- Pandas
- Plotly
- HTML
- CSS

## How It Works

1. User enters cultivation and market information.
2. The application processes the input data.
3. A machine learning model recommends a suitable crop.
4. XGBoost predicts the expected market price.
5. The application displays the prediction and useful cultivation advice.
6. The dashboard provides visual insights into crop prices and demand.
